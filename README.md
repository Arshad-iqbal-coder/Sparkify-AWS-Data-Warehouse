# Sparkify Data Warehouse Project

## Project Overview

Sparkify is a music streaming startup that wants to analyze the songs users are listening to and understand user activity on their platform. The company stores song metadata and application log data in Amazon S3 in JSON format. 

The purpose of this project is to build a cloud-based ETL pipeline using Amazon Redshift and AWS services. The pipeline extracts data from S3, stages the raw data in Redshift staging tables, and transforms it into analytics tables using a star schema design.

The final warehouse allows Sparkify’s analytics team to perform queries related to:
- Most played songs
- Most active users
- Peak listening hours
- User subscription levels
- Artist popularity

# Why Star Schema?

The star schema was chosen because it is optimized for analytical queries and business intelligence workloads.

## Benefits
- Faster query performance
- Simpler joins
- Easy aggregation and reporting
- Better organization of fact and dimension data

---

# ETL Pipeline

The ETL pipeline performs the following steps:

1. Create staging and analytics tables in Redshift.
2. Load raw JSON data from S3 into staging tables using the COPY command.
3. Transform and insert data into fact and dimension tables.
4. Run analytical queries on the warehouse.

---


# Pipeline Flow

```text
S3 JSON Data
      ↓
Staging Tables
      ↓
Transformation Queries
      ↓
Fact & Dimension Tables
      ↓
Analytics Queries

```

# Project Files

## create_tables.py
Creates staging and analytics tables in Amazon Redshift by executing DROP and CREATE statements.

---

## etl.py
Loads raw JSON data from S3 into Redshift staging tables using COPY commands and transforms the data into fact and dimension tables.

---

## sql_queries.py
Contains all SQL queries used in the project including:
- CREATE TABLE queries
- DROP TABLE queries
- COPY commands
- INSERT statements

---

## dwh.cfg
Stores Redshift cluster configuration, database credentials, IAM role ARN, and S3 paths.

---

## analytics.py
Runs analytical queries on the warehouse for validation and business insights.

# How to Run the Project

## 1. Configure AWS and Redshift

Update the `dwh.cfg` file with:
- Redshift cluster endpoint
- database name
- username and password
- IAM role ARN

---

## 2. Create Tables

Run the following command to create staging and analytics tables:

```bash
python create_tables.py
```

---

## 3. Run ETL Pipeline

Run the ETL pipeline to load data from S3 into Redshift:

```bash
python etl.py
```

---

## 4. Run Analytics Queries

Run analytics queries for validation and business insights:

```bash
python analytics.py
```
